# Section Setup Module

This module provides comprehensive functionality for managing sections in the HR system.

## Components

### SectionForm.vue
- **Purpose**: Form component for adding and editing section information
- **Features**:
  - Section name input with validation
  - Division selection (required)
  - Section chief selection from employees
  - Auto-generated section codes (read-only for existing sections)
  - Active/Inactive status toggle

### SectionTable.vue
- **Purpose**: Displays sections in a paginated table format
- **Features**:
  - Sortable columns (Code, Name, Division, Section Chief, Status)
  - Search and filter functionality
  - Pagination support
  - Edit action (no delete button as requested)
  - Loading states
  - Export functionality (Print, Excel, PDF)
  - Column visibility toggle
  - Responsive design

### SectionModal.vue
- **Purpose**: Modal wrapper for the SectionForm component
- **Features**:
  - Dynamic title (Add/Edit)
  - Form validation
  - Loading states
  - Proper modal behavior

### SectionFilters.vue
- **Purpose**: Search and filter controls for sections
- **Features**:
  - Search by name, code, chief, or division
  - Filter by status (Active/Inactive)
  - Add Section button
  - Responsive design

## Data Structure

### Section Object
```javascript
{
  id: number,
  code: string,           // Auto-generated (SC1001, SC1002, etc.)
  name: string,           // Required, min 3 characters
  division_id: number,    // Required, references divisions table
  section_chief_id: number, // Optional, section chief employee ID
  active: boolean,        // Active status
  supervisor: string,     // Computed field from employee data
  division: string        // Computed field from division data
}
```

## API Endpoints

- `GET /sections` - Get all sections
- `GET /sections/create` - Get form data (employees, divisions)
- `POST /sections` - Create new section
- `GET /sections/{id}/edit` - Get section for editing
- `PATCH /sections/{id}` - Update section
- `DELETE /sections/{id}` - Delete section
- `GET /sections/{id}` - Get section details

## Usage

### In SectionSetup.vue
```vue
<template>
  <SectionFilters @add="handleAddSection" />
  <SectionTable @edit="handleEditSection" />
  <SectionModal v-model="showModal" @submit="handleSaveSection" />
</template>
```

### With useSection Composable
```javascript

const {
```
