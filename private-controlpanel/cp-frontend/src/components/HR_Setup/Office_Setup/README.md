# Office Setup Module

This module provides comprehensive functionality for managing offices/departments in the HR system.

## Components

### OfficeForm.vue
- **Purpose**: Form component for adding and editing office information
- **Features**:
  - Office name input with validation
  - Branch selection (required)
  - Supervisor selection from employees
  - Functionality description (textarea)
  - Academic/Non-academic toggle
  - Active/Inactive status toggle
  - Auto-generated office codes (read-only for existing offices)

### OfficeTable.vue
- **Purpose**: Displays offices in a paginated table format
- **Features**:
  - Sortable columns (Code, Name, Supervisor, Type, Status)
  - Search and filter functionality
  - Pagination support
  - Edit and Delete actions
  - Loading states
  - Responsive design

### OfficeModal.vue
- **Purpose**: Modal wrapper for the OfficeForm component
- **Features**:
  - Dynamic title (Add/Edit)
  - Form validation
  - Loading states
  - Proper modal behavior

### OfficeFilters.vue
- **Purpose**: Search and filter controls for offices
- **Features**:
  - Search by name, code, or supervisor
  - Filter by type (Academic/Non-Academic)
  - Filter by status (Active/Inactive)
  - Add Office button
  - Responsive design

## Data Structure

### Office Object
```javascript
{
  id: number,
  code: string,           // Auto-generated (D1001, D1002, etc.)
  name: string,           // Required, min 3 characters
  functionality: string,  // Optional description
  branch_id: number,      // Required, references branches table
  employee_id: number,    // Optional, supervisor employee ID
  is_academic: boolean,   // Academic vs Non-academic
  active: boolean,        // Active status
  supervisor: string      // Computed field from employee data
}
```

## API Endpoints

- `GET /departments` - Get all offices
- `GET /departments/create` - Get form data (employees, branches)
- `POST /departments` - Create new office
- `GET /departments/{id}/edit` - Get office for editing
- `PATCH /departments/{id}` - Update office
- `DELETE /departments/{id}` - Delete office
- `GET /departments/{id}` - Get office details

### In OfficeSetup.vue
```vue

  <OfficeFilters @add="handleAddOffice" />
  <OfficeTable @edit="handleEditOffice" @delete="handleDeleteOffice" />
  <OfficeModal v-model="showModal" @submit="handleSaveOffice" />
```
