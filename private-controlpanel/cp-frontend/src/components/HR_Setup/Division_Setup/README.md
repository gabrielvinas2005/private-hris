# Division Setup Module

This module provides comprehensive functionality for managing divisions in the HR system.

## Components

### DivisionForm.vue
- **Purpose**: Form component for adding and editing division information
- **Features**:
  - Division name input with validation
  - Department selection (required)
  - Division chief selection from employees
  - Auto-generated division codes (read-only for existing divisions)
  - Active/Inactive status toggle

### DivisionTable.vue
- **Purpose**: Displays divisions in a paginated table format
- **Features**:
  - Sortable columns (Code, Name, Department, Division Chief, Status)
  - Search and filter functionality
  - Pagination support
  - Edit action (no delete button as requested)
  - Loading states
  - Export functionality (Print, Excel, PDF)
  - Column visibility toggle
  - Responsive design

### DivisionModal.vue
- **Purpose**: Modal wrapper for the DivisionForm component
- **Features**:
  - Dynamic title (Add/Edit)
  - Form validation
  - Loading states
  - Proper modal behavior

### DivisionFilters.vue
- **Purpose**: Search and filter controls for divisions
- **Features**:
  - Search by name, code, chief, or department
  - Filter by status (Active/Inactive)
  - Add Division button
  - Responsive design

## Data Structure

### Division Object
```javascript
{
  id: number,
  code: string,           // Auto-generated (DV1001, DV1002, etc.)
  name: string,           // Required, min 3 characters
  department_id: number,  // Required, references departments table
  division_chief_id: number, // Optional, division chief employee ID
  active: boolean,        // Active status
  division_chief: string, // Computed field from employee data
  office: string          // Computed field from department data
}
```

## API Endpoints

- `GET /divisions` - Get all divisions
- `GET /divisions/create` - Get form data (employees, departments)
- `POST /divisions` - Create new division
- `GET /divisions/{id}/edit` - Get division for editing
- `PATCH /divisions/{id}` - Update division
- `DELETE /divisions/{id}` - Delete division
- `GET /divisions/{id}` - Get division details

## Usage

### In DivisionSetup.vue
```vue

  <DivisionFilters @add="handleAddDivision" />
  <DivisionTable @edit="handleEditDivision" />
  <DivisionModal v-model="showModal" @submit="handleSaveDivision" />
</template>
```
